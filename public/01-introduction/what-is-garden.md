# What is Garden?
Garden is a private digital environment made of Places, atmosphere, objects, rituals and selected memories.

A person can create a Place, shape how it feels, return later and ask AI to suggest changes. AI may propose, but only the person decides what becomes part of Garden.

`Create a Place → shape its atmosphere → add objects → create a ritual → leave → return → preview an AI suggestion → apply or reject it → undo when needed`

Garden is built around authorship, return, privacy and reversibility.
