# Decisions

[registry.json](registry.json) is the machine-readable decision status and provenance index. [Decision Log](decision-log.md) is generated from it. `design-rules.md` preserves historical proposals; `gdr/` contains recovered accepted owner amendments; `adr/` contains architecture and delivery decisions. An accepted collection does not accept its embedded proposals.
