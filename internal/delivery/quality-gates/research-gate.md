# Research Gate

- Core flows work without facilitator repair.
- Preview cannot mutate committed data.
- Undo is visible and functional.
- Drafts survive refresh.
- Analytics contain no private user-authored text.
- Error and offline states are demonstrable.
- Keyboard navigation completes all core tasks.
