# P-002 — Core User Flows

## First Garden
```text
Open → blank/guided start → create Place → set atmosphere → add Object → optional Ritual → enter → leave → return directly
```

## Manual edit
```text
Place → Edit → change → Preview → Save → Version → Undo
```

## AI edit
```text
Place → Ask AI → select scope → assumptions → proposal → Preview → partial/full Apply or Reject → Version → Undo
```

## Ritual
Create name, optional description/place/reminder, save. No streak and no missed state.

## Memory
Create text/media/date, choose one primary Place, optional Ritual/Object, save.

## Data rights
Settings → Data → Export/Delete → consequences → confirmation → receipt.

Every flow includes offline, failed save, stale version, AI timeout, conflict and restore paths.

> Every meaningful action is reversible or explained before commitment.
