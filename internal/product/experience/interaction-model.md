# P-003 — Interaction Model

## Layers
- L0 Observe
- L1 Focus
- L2 Adjust
- L3 Compose
- L4 Transform

Higher levels require stronger preview and confirmation.

## Patterns
- direct manipulation;
- explicit selection;
- preview before commit;
- partial acceptance;
- version creation;
- Undo;
- provenance;
- quiet dismissal.

Objects are affordances, not collectibles. No rarity, price, level or reward value.

AI is invoked, never ambient. Every request exposes scope, intent, assumptions, affected entities, proposal, preview, commit and undo reference.

> Garden should feel like shaping a place, not operating a control panel.
