## Imported source: `garden_transition_to_development_v0_1.md`

# Transition to Development

Week 1: approve Alpha Constitution, create information architecture and core flow, freeze entities and AI actions.

Week 2: build HTML prototype and test first-session, first-return and Preview/Apply/Undo.

Week 3: revise scope, define technical architecture, build threat model and begin vertical slice.

Development starts after five to eight users complete the first-place flow and privacy, deletion, AI approval, versions and Undo are stable.

# Garden Phase 3 — Coded Vertical Slice

Build:
- Welcome;
- First Place Setup;
- Garden Home;
- Place View;
- Atmosphere;
- Object Library and Placement;
- Ritual Editor;
- Direct Return;
- AI Request and Assumptions;
- Preview and Partial Apply;
- History and Undo;
- Privacy/Data stub.

Priorities:
1. Draft, Preview and Committed state separation.
2. Responsive Place Renderer.
3. Keyboard and structured representation.
4. Deterministic AI proposals.
5. Version history.
6. Local persistence.
7. Research instrumentation.

Deferred:
- live AI;
- production authentication;
- collaboration;
- social features;
- production backend.
