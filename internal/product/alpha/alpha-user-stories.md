# Garden Prototype User Stories

## First place
As a new user, I can begin with one place without completing a profile.

## Authorship
As a user, I can change atmosphere and objects and know what is draft versus saved.

## Return
As a user, I can leave and return directly to the same preserved place.

## Ritual
As a user, I can create a ritual without committing to frequency or streaks.

## Memory
As a user, I can preserve a memory without the system interpreting it.

## AI scope
As a user, I can see what AI may read before requesting a proposal.

## AI preview
As a user, I can inspect and partially apply AI changes before anything becomes real.

## Undo
As a user, I can undo manual and AI changes through version history.

## Privacy
As a user, I can understand ownership, export and deletion.

## Accessibility
As a user who cannot or does not want to use spatial interaction, I can access all functions through a structured interface.
