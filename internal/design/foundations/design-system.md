# P-005 — Design System

## Foundations
Color roles, 8-point spacing, restrained radius/elevation, accessible typography and visible focus.

## Core components
Garden Shell; Place Canvas; Direct Navigation; Search; Context Card; Object Inspector; Ritual Card; Memory Card; Atmosphere Controls; AI Composer; Assumptions Panel; Preview; Diff; Partial Apply; Version Timeline; Undo; Privacy Panel; Export/Delete Dialog; Quiet Empty State; Error and Offline states.

## Ethical component rules
- destructive actions explain consequences;
- AI components expose scope and commit state;
- notifications show provenance;
- empty states avoid pressure;
- no drag-only interaction.

Accessibility includes keyboard, reduced motion, screen readers, scalable type and non-spatial navigation.

> The design system encodes product ethics, not only consistency.
