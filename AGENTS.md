# Instructions for AI Agents
- The entire repository is public; GitHub Pages is disabled.
- `public/` is candidate publication content, not a currently public site.
- `internal/` and `archive/` are publicly readable; folder names specify audiences, not access control.
- Keep confidential material, credentials and raw participant data outside this public repository.
- Never move, copy or summarize internal content into public pages without an explicit publication task and human approval.
- Read `internal/governance/SOURCE_OF_TRUTH.md` and `PUBLICATION_POLICY.md` before public work.
- Never expose secrets, raw research data, threat details, internal URLs, prompts, eval fixtures or unannounced commitments.
- AI proposes; humans approve Canon, publication, security/privacy, production and expanded private-context access.
- Never create a competing source of truth or treat archived files as active requirements.

- Follow the registered accepted decisions; historical proposal collections do not approve their embedded proposals.
- First cycle: Place, Save, Leave, Return; consult the current slice specification before implementing broader Alpha requirements.
- AI Ops Kit 4.9.3 is installed with protected paths and manual updates. Preserve managed checksums; use project overlays. Installation does not complete reference-product qualification. Garden Canon and these instructions take precedence over operational scaffolds.
